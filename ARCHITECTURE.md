# Aruna's Annam V1 Architecture

Customer:
Flutter Android app -> REST API -> Database

Admin:
Web dashboard -> REST API -> Database

Core database entities:
- users
- addresses
- menu_items
- orders
- order_items
- subscriptions
- delivery_zones
- payments

- Razorpay payment gateway
- Maps/location + delivery zone validation

- Delivery partner app
