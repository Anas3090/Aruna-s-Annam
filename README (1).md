# Aruna's Annam — Frontend Prototype

Mobile-first prototype for a homemade-food delivery service around Sholinganallur.

Included:
- Customer home screen
- Today's menu
- Add-to-cart interaction
- Monthly meal plans
- How-it-works section
- Bottom navigation

Next build stages:
1. Customer login/signup
2. Menu/category/product management
3. Cart + address + delivery slot
4. Online payment
5. Order tracking
6. Admin dashboard
7. Backend/database
8. Delivery-partner app
